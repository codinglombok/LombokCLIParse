# LombokCLIParse for Python

Python package `lombokcliparse` (Python 3.9+): positional arguments, flags, typed options, subcommands, environment fallback and generated help, with the same results, error messages and help text as the other LombokCLIParse ports. Zero runtime dependencies.

```
pip install lombokcliparse
```

Behaviour is defined in [docs/SPEC_LombokCLIParse_v0.2.0.md](https://github.com/codinglombok/LombokCLIParse/blob/main/docs/SPEC_LombokCLIParse_v0.2.0.md); this port runs the shared vector file in CI. Usage for all languages: [main README](https://github.com/codinglombok/LombokCLIParse#readme) and [docs/API_LombokCLIParse_v0.2.0.md](https://github.com/codinglombok/LombokCLIParse/blob/main/docs/API_LombokCLIParse_v0.2.0.md).
